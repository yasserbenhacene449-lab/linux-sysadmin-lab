# ⚙️ Week 03: Package Management, Systemd Services & Troubleshooting Workflows

Hands-on lab documentation focusing on Linux software distribution architecture, system daemon control, and enterprise diagnostic methodologies.

---

## 🎯 Key Learning Outcomes

### 1. Software & Package Management Concepts
- Understanding the repository model in Enterprise Linux environments.
- Differentiating between raw package archives (`.rpm` / `.deb`) and automated dependency resolution managers (`dnf`, `yum`, `apt`).
- Analyzing package metadata, software versions, dependencies, and repository channels.

### 2. Service Architecture & Daemon Control (`systemctl`)
- Demystifying background processes (Daemons) and their role in hosting server infrastructure.
- Mastered the systemd init system and unit file structures (`.service`).
- Navigating the complete lifecycle of system services: execution, interruption, persistence across reboots, and status verification.

### 3. Junior Cloud Administrator Troubleshooting Framework
- Systematically diagnosing missing binaries, path resolution errors, and inactive network services.
- Analyzing runtime failure logs to isolate configuration syntax issues from dependency constraints.
- Validating system state before and after service modifications to ensure operational stability.

---

## 🧪 Applied Lab Scenarios Executed

- **Web Server Deployment & Lifecycle Verification:** Evaluated package installation states, verified service daemon initialization, and managed system startup behavior.
- **Service Diagnostics:** Handled missing unit file exceptions, inspected background process states, and validated log outputs for execution errors.
